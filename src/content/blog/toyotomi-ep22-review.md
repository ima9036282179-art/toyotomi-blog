## 第22話「播磨大誤算」（2026年6月7日放送）

勝ったはずだった。播磨を手中に収めたはずだった——。しかし第22話は、秀吉（池松壮亮）の「勝利」が砂上の楼閣だったことを容赦なく暴きます。服属したはずの国衆が次々と反旗を翻し、竹中半兵衛（菅田将暉）の体調は悪化し、毛利・宇喜多まで動き出す。窮地に追い込まれた秀吉はついに記憶を失い、今度は**小一郎が兄を救う番**が来ます。

## あらすじ

播磨平定は成ったかに見えた。しかし竹中半兵衛（菅田将暉）の悪い予感が的中する。服属したはずの播磨の国衆たちが次々と反旗を翻し、呼応するように安芸の**毛利**、備前の**宇喜多**も挙兵。羽柴軍は播磨で孤立する危機に陥る。

折悪く半兵衛の体調が急激に悪化。戦場の指揮どころではなくなった半兵衛を抱え、秀吉は味方の国衆を見捨てるかたちで撤退を余儀なくされる。

**「自分のせいで仲間が死んだ」**——自責の念にさいなまれた秀吉はある夜、足を踏み外して頭を打ち、記憶を失ってしまう。自分が誰か、何をしてきたか——何もわからなくなった兄を前に、小一郎（仲野太賀）は記憶を取り戻させようと必死に手を尽くす。

## 第22話を読み解く5つのキーワード

### 1. 国衆の反乱——「播磨大誤算」の正体

播磨の国衆が離反したのは突然の裏切りではありません。もともと播磨は織田と毛利の狭間で揺れ続けた土地。「今は織田方」であっても、毛利が動けば瞬時に寝返る国衆が多くいました。

半兵衛が「悪い予感」を持っていたのは、この構造的な不安定さを見抜いていたからです。戦略的に「勝った」と見えても、相手の心まで掌握できていたわけではなかった——播磨平定の「誤算」の本質はそこにあります。

### 2. 竹中半兵衛の体調悪化——「死の予感」

今回最も重い展開が、竹中半兵衛（菅田将暉）の体調悪化です。

史実では半兵衛は天正7年（1579年）に播磨三木城攻めの最中に病死します。享年35歳。第22話での体調悪化は、その最期への「始まり」を描いていると見てよいでしょう。菅田将暉という大きなキャストが演じる半兵衛だからこそ、その「失われる前の輝き」が余計に胸に刺さります。

### 3. 毛利・宇喜多の挙兵——西国の複雑な力学

毛利と宇喜多が動いたことで、秀吉の西国経略は新たな局面を迎えます。特に宇喜多氏（備前・岡山）は、毛利と織田の間で巧みに立場を変えてきた難敵です。

この「全方位からの圧力」こそが、秀吉を精神的に追い詰める直接の原因となります。

### 4. 秀吉の記憶喪失——ドラマが問う「自分とは何か」

「記憶喪失」というドラマ的な装置は、このドラマにとって単なる衝撃展開ではありません。

秀吉という人間の本質——何が彼を動かしているのか、何のために戦っているのか——をリセットしたうえで問い直す構造です。記憶を失った秀吉が小一郎の言葉や行動に何を感じ、どう「秀吉」を取り戻すか。そこにこのドラマが描いてきた兄弟の核心があります。

### 5. 小一郎が「兄を救う」——役割の逆転

第1話から22話まで、秀吉が窮地に立ったとき必ず小一郎がいました。しかし今回は局面が違います。体も心も壊れた兄を、弟が「存在」として支え直す場面です。

武力でも策略でも知恵でもなく——「おまえは秀吉だ」と伝え続ける小一郎の姿は、このドラマにおける小一郎像の集大成に近いものになるはずです。

竹中半兵衛を演じる菅田将暉は、これまで「冷静な軍師」として圧倒的な存在感を放ってきました。その半兵衛が体調を崩し、限界を迎える姿を菅田将暉がどう演じるか——これが第22話最大の見どころのひとつです。

「頭脳が衰えていく人間」の演技は役者の真価が問われます。半兵衛の病は史実でも悲劇として語り継がれており、その「知性の灯火が消えていく過程」を菅田将暉がどう表現するか。見逃せません。

また、秀吉や小一郎が半兵衛の病をどう受け止めるかという「周囲の反応」にも注目です。頼れる知恵袋を失っていく不安と悲しさを、池松壮亮・仲野太賀がどう体で表現するか。

### 見どころ② 秀吉の「崩壊」——池松壮亮の挑戦

自責の念から記憶を失うという展開は、池松壮亮にとって大きな演技的挑戦です。

池松壮亮は今作で、「普通の人間としての秀吉」を繊細に描いてきました。英雄的な豪快さではなく、迷い・怖れ・後悔を持つ人間としての秀吉。その「人間」としての核が崩れる瞬間——記憶を失い、自分が誰かわからなくなった秀吉の演技は、今作最大の見場のひとつになるはずです。

「記憶を失った秀吉」がどんな顔をしているのか。無垢か、茫洋か、それとも怯えか——そこに池松壮亮の答えが出ます。

### 見どころ③ 小一郎の言葉——「おまえは秀吉だ」

記憶を失った兄に、小一郎は何を語りかけるのか。

このドラマが第1話から積み重ねてきた「二人の記憶」——泥臭く這い上がった日々、死にそうになりながら笑った瞬間、二人にしかわからない言葉——を小一郎が語るシーンは、視聴者にとっても「22話分の総まとめ」になります。

仲野太賀の演技において、泣かせようとしない静けさの中に感情を閉じ込める技術は随一です。「おまえは秀吉だ」と言い聞かせる場面で、どれだけ静かに、どれだけ深く泣けるか——そこが第22話のクライマックスになるでしょう。

### 見どころ④ 撤退の決断——「見捨てる」秀吉

半兵衛の病悪化により秀吉が味方を見捨てて撤退する場面も、道徳的に重い見どころです。

戦略的には正しい判断かもしれない。しかし仲間を見捨てることで生き延びた事実が秀吉を壊します。「勝つために人を切り捨てる」判断の重さ——それが記憶喪失という形で身体化されるという演出は、このドラマの脚本の鋭さを示しています。

### 竹中半兵衛の実像——「戦わずして勝つ」天才軍師の生涯

#### 伝説的な稲葉山城乗っ取り

竹中半兵衛（重治）は天文13年（1544年）、美濃国（現・岐阜県）の武将の家に生まれました。その名を一躍天下に知らしめたのが、永禄7年（1564年）——わずか**16人の手勢**で主君・斎藤龍興の居城・稲葉山城（岐阜城）を乗っ取ったという伝説的なエピソードです。

このとき半兵衛はまだ20歳。占領後も城を自分のものにするつもりはなく、数ヶ月後に静かに城を返還して引退しています。「勝てばいいわけではない。城を欲しかったわけでもない」——この行動が半兵衛という人間の本質をよく表しています。

#### 秀吉との出会い——「三顧の礼」

その後、半兵衛は一度隠居しますが、織田信長の家臣として頭角を現していた木下秀吉（羽柴秀吉）が何度も足を運び、ようやく家臣に迎えました。

この「三顧の礼」に似たエピソードは、三国志の諸葛孔明と劉備の逸話と重ねられ、後世に美談として語り継がれています。半兵衛が秀吉に仕えたのは「信長への奉公」としてではなく、「秀吉個人への義理」という意識があったとされます。

#### 「二大軍師」と呼ばれた理由

| 項目 | 竹中半兵衛 | 黒田官兵衛 |
|------|----------|----------|
| 役割 | 奇策・心理戦に長けた軍師 | 実行力・調略に長けた軍師 |
| 個性 | 飄々として読めない | 冷静で現実的 |
| 秀吉との関係 | 内側から支える参謀 | 外向きの交渉・戦略を担う |
| 最期 | 35歳で陣中病死 | 秀吉没後まで生き延びる |

半兵衛と官兵衛は後に「羽柴軍の二大軍師」と並び称されます。2人の性格は対照的で、飄々とした半兵衛と現実的な官兵衛が補い合う関係でした。

#### 官兵衛の息子を救った話

半兵衛が残した最も有名な「義の行動」が、黒田官兵衛の息子・松寿丸（後の黒田長政）を救った件です。

荒木村重が謀反を起こした際、官兵衛は単身説得に赴いて逆に幽閉されてしまいます。信長は「官兵衛も村重に内通したのではないか」と疑い、人質として預かっていた松寿丸（官兵衛の息子）を殺すよう命じます。しかし半兵衛はこれを拒否。松寿丸を自分の領地に密かに匿い、官兵衛が解放されるまで生かし続けました。

この判断によって、黒田家の血筋は守られたのです。半兵衛はすでに病で余命が限られていることを知りながら、このリスクを引き受けました。

#### 陣中での最期

| 項目 | 内容 |
|------|------|
| 生年 | 天文13年（1544年） |
| 没年 | 天正7年（1579年）6月13日 |
| 享年 | 35歳 |
| 死因 | 肺結核（陣中での病死） |
| 没地 | 播磨・平井山の陣中 |
| 辞世の句 | 「攻めかかる 雲霧ならば 苦しまじ 月は入れども また出ずるとも」（異説あり） |

半兵衛は三木城攻めの最前線の陣中で病に倒れ、そのまま35歳で息を引き取りました。秀吉は深く嘆き悲しんだと伝わります。以降、参謀役は官兵衛が一人で担うことになりました。

### 別所長治の実像——22歳の城主が選んだ最期

#### 播磨の名家・別所氏とは

別所氏は播磨国（現・兵庫県）の有力豪族で、三木城（現・兵庫県三木市）を本拠としていました。別所長治（1558〜1580年）は天正5年（1577年）、父の急死により弱冠19歳で家督を継ぎます。

#### なぜ裏切ったのか——複数の説

| 説 | 内容 |
|----|------|
| 毛利の工作説 | 毛利氏が積極的に調略し、国衆を引き込んだ |
| 秀吉への不満説 | 播磨統治において秀吉の要求が苛烈だったことへの反発 |
| 自律性の確保 | 織田に完全に従属することへの国衆としての抵抗 |
| 叔父・別所賀相の主導説 | 長治本人よりも叔父が主導した可能性が高い |

実態は複合的で、「信長・秀吉への個人的な恨み」というより**「播磨の国衆として生き残るための計算」**と「毛利の積極的な調略」が組み合わさったものと見られています。長治はまだ20歳であり、叔父たちの影響を強く受けていたとする研究者も多くいます。

#### 「三木の干殺し」——2年間の兵糧攻め

秀吉は力攻めではなく、兵糧を完全に断つ戦略を選択しました。城の周囲に多数の砦（付城）を築き、補給路をすべて遮断する——これが「**三木の干殺し（みきのひごろし）**」と呼ばれる兵糧攻めです。

| 時期 | 状況 |
|------|------|
| 天正6年（1578年）3月〜 | 三木城包囲開始 |
| 天正6〜7年 | 毛利が援軍・兵糧を送ろうとするも秀吉が阻止 |
| 天正7年末頃 | 城内で食糧が底をつき、餓死者が続出 |
| 天正8年（1580年）1月17日 | 別所長治が降伏・自害 |

城内の兵士・住民は餓死・病死が相次ぎ、最終的に2万人以上が城に籠もった状態で約2年を耐えました。

#### 別所長治の自害と辞世の句

天正8年1月、別所長治は城兵の助命を秀吉に嘆願したうえで、妻・照子、弟・友之とともに自害しました。享年22歳。

> **「今はただ 恨みもあらじ 諸人の 命に代わる 我が身と思えば」**

「もはや恨みはない。みんなの命の代わりに、自分が死ぬのだと思えば」——この辞世の句は後世に広く伝わり、長治は「主君を慕う家臣のために命を捧げた悲劇の武将」として語り継がれています。

秀吉は長治の器量と潔い最期を惜しんだとも伝わり、城兵への乱暴を厳しく禁じたとされます。

**ドラマでの描写：** 第22話ではまだ三木城の攻防は始まったばかりです。この「2年間の苦闘とその結末」は、ドラマ後半の大きな軸となるはずです。

### 宇喜多直家の実像——謀略と生存の帝王

#### 「下剋上の申し子」——浦上氏の家臣から戦国大名へ

宇喜多直家（1529?〜1581年）は備前国（現・岡山県）の戦国大名です。もともとは備前の有力大名・浦上氏の家臣に過ぎませんでしたが、謀略・暗殺・政略婚を駆使して頭角を現し、最終的には主君・浦上氏を乗っ取って備前一国の主となりました。

まさに**「下剋上の申し子」**と呼ぶにふさわしい人物です。

#### 直家の謀略——暗殺と政略婚

直家が生き残るために使った手段は、当時の戦国武将の中でも特に苛烈でした。

| 手段 | 内容 |
|------|------|
| 暗殺 | 邪魔な相手を暗殺者に命じて除去。主君・浦上氏の重臣も含む |
| 政略婚 | 娘・お福を多くの有力者に嫁がせ、縁戚関係を築く |
| 毒殺疑惑 | 舅にあたる人物が急死しており、毒殺の疑いが根強い |
| 降伏と反転 | 一度降伏して相手を油断させ、機を見て寝返る |

こうした行動から、直家は「戦国一の謀略家」として現代でも高い（悪）名声を持ちます。ただし、彼の謀略は「弱者が大国の狭間で生き残るための必死の手段」でもありました。

#### 「両属」の本質——生存のための綱渡り外交

宇喜多氏が毛利と織田の両方に顔を持っていた背景には、備前という地の特殊な位置関係があります。

| 時期 | 宇喜多の立場 | 背景 |
|------|------------|------|
| 〜1575年頃 | 毛利方（西の大勢力に従属） | 毛利が中国地方最強だったため |
| 1575〜78年 | 織田方へ接近 | 秀吉の播磨進出で織田の勢力拡大を察知 |
| 1578年頃 | 再び毛利方へ | 別所長治離反など反秀吉の流れに乗る |
| 1579〜80年 | 秀吉方へ最終帰順 | 毛利方の劣勢と秀吉の優遇条件 |

直家の「両属」は単なる日和見ではありません。「どちらが有利かを常に計算し、いつでも乗り換えられる体制を整え続ける」という**積極的な生存戦略**でした。ただし、これは信義を軽視することと表裏一体であり、同時代の人々からも「信用できない男」と見られていました。

#### 直家の最期と息子・秀家の運命

宇喜多直家は最終的に秀吉への帰順を選んだものの、天正9年（1581年）に病死します。秀吉と直接対面することなく世を去りました。

その後、直家の息子・**宇喜多秀家**は豊臣政権下で五大老のひとりに昇り、備前57万石の大大名となります。しかし関ヶ原の戦い（1600年）では西軍に加わり、敗れて八丈島に流罪となり、50年以上島で生き続けました。父の謀略家ぶりとは対照的な、義理を重んじた最期でした。

**ドラマでの描写：** 宇喜多の「再び毛利方へ」という動きは、第22話時点では秀吉にとって明確な脅威です。この後、どのように秀吉方へ取り込まれていくかが後半の見どころのひとつになります。

### 荒木村重の謀反——この時期に起きていたもうひとつの「誤算」

史実では天正6年（1578年）10月、信長の重臣・荒木村重が突如謀反を起こし、有岡城（現・伊丹市）に籠城します。これも秀吉の播磨経略と同時期に起きた大事件です。

第21話で「村重の仲介で官兵衛と出会った」という設定があったことを踏まえると、この後の荒木村重の裏切りがドラマでどう描かれるかも注目点です。また、官兵衛が村重を説得しようとして逆に幽閉される（史実）という展開が来るとすれば、その伏線が第22話のどこかに潜んでいる可能性があります。

---

### 秀吉の「記憶喪失」——史実にはない、ドラマの創作

秀吉が記憶を失うというエピソードは**史実には存在しません**。これはドラマの完全な創作です。

しかし創作だからこそ、脚本家・八津弘幸が「秀吉というキャラクターに何を問いたかったか」が明確に見えます。

史実の秀吉は播磨での苦戦（三木城攻め、別所長治の離反、荒木村重の謀反）の中でも、精神的に折れることなく戦い続けました。しかしこのドラマは「**そのとき秀吉の内側で何が起きていたか**」を問います。仲間を見捨てた自責、半兵衛を失っていく恐怖——その重さを「記憶喪失」という形で可視化した演出です。

---

## 第23話への伏線・予告

秀吉の記憶が戻るかどうかが次回の軸になります。しかしそれ以上に注目すべきは**竹中半兵衛の病の行方**です。史実を知る視聴者には、半兵衛が生き延びないことがわかっています。その「知っているのに見てしまう」緊張感が、第23話以降の大きな見どころになります。

また播磨は依然として不安定であり、別所長治の三木城攻めという長期戦が待っています。秀吉が記憶を取り戻したとき、どんな顔でその現実に向き合うのか——第22話ラストから第23話冒頭への流れが重要になります。

---

## まとめ

| 見どころ | ポイント | 史実との関係 |
|--------|--------|------------|
| 国衆の反乱 | 播磨平定の「誤算」が露わに | 別所長治の離反は史実通り |
| 半兵衛の体調悪化 | 菅田将暉の渾身の演技 | 史実では1579年に陣中で病死 |
| 毛利・宇喜多の挙兵 | 西国の複雑な力学 | 宇喜多の両属は史実的事実 |
| 秀吉の記憶喪失 | 池松壮亮の演技的挑戦 | ドラマ創作。自責の可視化 |
| 小一郎の奔走 | 「兄を救う弟」の真骨頂 | 史実の秀長は秀吉を最後まで支えた |

**史実のポイント：**
- 播磨国衆の離反（別所長治）は史実通りで秀吉最大の苦境
- 竹中半兵衛の病悪化は死への「始まり」——史実では1579年に35歳で病死
- 秀吉の記憶喪失はドラマ創作、「自責の重さ」を可視化した演出
- 宇喜多・荒木村重の動向は史実の混乱を反映

第22話は「勝利の後に来る崩壊」を描く回です。播磨が崩れ、半兵衛が倒れ、秀吉が壊れる——それでも小一郎は立っている。この兄弟の物語が22話かけて積み上げてきたものが、今回の「兄を取り戻す」場面に全部乗っています。
